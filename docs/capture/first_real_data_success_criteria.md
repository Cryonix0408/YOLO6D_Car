# 第一批真实数据成功标准

本文档用于判断第一批真实采集数据是否“可以进入训练/实验”。

## 采集成功

一组 session 至少应包含：

- `images/` 或连续帧图像目录
- `camera_timestamps.csv`
- `config.yaml`
- 对应 FzMotion CSV
- session 名称清楚，能看出日期、距离、背景、光照或运动类型

## 相机成功

海康相机采集应满足：

- 图像不过曝。
- 图像不是严重欠曝。
- 运动目标没有完全糊成一团。
- 帧率接近设定值。
- `camera_timestamps.csv` 时间戳连续。
- `config.yaml` 记录了曝光、增益、fps、分辨率。

## Mocap 成功

FzMotion CSV 应满足：

- 能被 `check_mocap_csv.py` 识别。
- 包含相机刚体。
- 包含小车刚体。
- 有效帧数量足够。
- 没有大面积 NaN。
- 时间范围覆盖图像采集时间。

## 标签成功

自动标签应满足：

- `saved_labels` 大于 0。
- overlay 中关键点贴在小车上。
- 线框没有整体飞走。
- 小车不同距离、不同角度下标签都基本合理。
- 可视化报告没有大量缺图或缺标签。

## 训练成功

训练初版模型应满足：

- `best.pt` 生成。
- loss 正常下降。
- 验证集指标不是全 0。
- 用真实图片推理能稳定检测小车。

## fast-moving 初版成功

fast-moving 初版不要求完美，但至少应满足：

- 连续帧能稳定采集。
- 目标进入画面时能被检测。
- 位姿输出不频繁崩溃。
- Kalman 后轨迹比 raw 更平滑。
- 可以保存结果用于后续评估。
