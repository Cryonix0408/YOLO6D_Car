# docs/archive 归档说明

`docs/archive/` 建议用于存放阶段性验收报告、迁移记录、同步记录和历史过程文档。这里不是当前主流程入口，而是给后续复盘、交接和追踪历史决策使用。

本轮安全精简只创建归档说明，不移动任何文件、不删除任何文件、不重命名任何文件。

后续如果确认这些文档不再作为日常入口使用，可以在单独 PR / commit 中移动到本目录，并同步更新 `docs/index.md` 和 README 链接。
